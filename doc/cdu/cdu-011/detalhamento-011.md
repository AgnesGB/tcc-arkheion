# CDU011. Adicionar bônus de Atributo.

- **Ator principal**: Usuário
- **Atores secundários**: ---
- **Resumo**: O usuário adiciona um bônus a um atributo.
- **Pré-condição**: ---
- **Pós-Condição**: ---

## Fluxo Principal
| Ações do ator | Ações do sistema |
| :-----------------: | :-----------------: | 
| 1 - Entra na tela de personagem. | 2 - Exibe a tela de Personagem. |  
| 3 - Clica na opção de vizualização de ficha de personagem. | 4 - Exibe a tela de ficha já devidamente preenchida. |
| 5 - Escolhe, dentre as opções de atributo, um para adicionar o bônus, e clica no botão de +. | 6 - Abre uma janela para digitar o número e confirmar a inserção do bônus. |
| 7 - Adiciona o valor e confirma a inserção do bônus. | 8 - Volta para a página de vizualização de ficha com o valor do atributo atualizada. |

## Fluxo Alternativo I - Caractere Inválido.
| Ações do ator | Ações do sistema |
| :-----------------: |:-----------------: |   
| 7.1 - Preenche os dados nos campos informados incorretamente, com caracteres inválidos. | 8.1 - Envia um aviso de caractere inválido, pedindo para que tente novamente. A ação se repete até que os dados sejam inseridos corretamente. |
| 9.1 - Insere os dados corretamente. | 10.1 - Autentica os dados e volta para a página de vizualização de ficha com o valor do atributo atualizada. |
